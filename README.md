# Twitch chat overlay

Локальный прозрачный оверлей для OBS. Персонаж появляется после первого сообщения пользователя в чате, а через 5 минут без сообщений исчезает. Все персонажи ходят в одном ряду по нижнему краю. При встрече пары есть 1% шанс, что один толкнёт другого: упавший остаётся лежать до своего следующего сообщения. Облачко показывается на 6 секунд. После перезагрузки страница начинается пустой.

## Запуск

Нужен Node.js 20 или новее.

```powershell
npm run dev
```

Откройте `http://localhost:5173/` в браузере и в появившемся окне введите никнейм стримера или ссылку на его Twitch-канал. После выбора канал появится в адресе: `http://localhost:5173/<канал>`. Этот адрес можно добавить в OBS как Browser Source, чтобы при следующем открытии подключаться без запроса. Для просмотра состояния подключения добавьте `?debug=1` к адресу канала.

Для проверки внешнего вида без ожидания сообщений добавьте `?preview=1` к локальному адресу канала. В этом режиме показываются три тестовых персонажа, подключение к Twitch не создаётся.

Для OBS задайте размер источника равным размеру сцены, например 1920 × 1080. Фон страницы прозрачный. Когда зрители молчат, страница выглядит пустой.

## Netlify

Production-страница: <https://twitch-chat-overlay.netlify.app/>. На главной странице можно ввести никнейм или ссылку на канал. Прямой адрес `https://twitch-chat-overlay.netlify.app/<канал>` открывает выбранный канал без запроса.

После входа в Netlify и привязки проекта обновите публикацию командой:

```powershell
npx netlify-cli deploy --prod
```

Команда запускает `npm run build` и публикует только страницу и её ресурсы из `dist/`.

## Ограничение подключения

Оверлей использует анонимное read-only подключение к Twitch IRC. Оно работало во время разработки, но официальная документация Twitch описывает чтение чата с токеном. Twitch может изменить работу анонимного подключения. Страница получает только новые сообщения после открытия и не может показать список всех зрителей или прошлые сообщения.
